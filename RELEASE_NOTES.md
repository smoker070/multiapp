## Multiapp 0.3.2

- A new sidebar layout with a Sessions picker; the backup window opens at once.
- A Trash screen: see what was deleted, restore profiles, or empty it.
- Move Claude sessions between accounts, not only between profiles (macOS).
- Windows: one app running as administrator no longer blocks every other profile; the list no longer flickers.

## Multiapp 0.3.1

- A real desktop window on Windows, with an installer and a Start Menu entry.
- Backup, restore and app discovery now work on Windows too.
- Settings with English, O‘zbekcha and Русский and a dark or light theme; probe an app from the window.

## Multiapp 0.3.0

- First public release: create, launch, stop, clone, rename and delete separate profiles of the same app.
- Back up an app's data, or save just its login, and restore it later; restores never delete what is already there.
- A macOS menu-bar app, a portable command line for Windows and Linux, and clickable per-profile launchers.
